# wilyhq/scoop-bucket

Scoop bucket for [wily](https://wily.bot).

```powershell
scoop bucket add wilyhq https://github.com/wilyhq/scoop-bucket
scoop install wilyhq/wily-cli
```

No release has been published yet — the manifest appears here with the first public release.
Binaries are downloaded from `updates.wily.bot`; this repository holds only the manifests,
updated by the release pipeline.
